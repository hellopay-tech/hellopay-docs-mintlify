## Install the Agent Skill

The **hellopay-payments** skill teaches an agent how to create payins and payouts, generate payment links, choose between PSE, Bre-B, and Nequi, poll async transactions, and handle webhooks. It follows the open [Agent Skills](https://agentskills.io/specification) standard and lives in [`skills/hellopay-payments`](https://github.com/hellopay-tech/hellopay-docs-mintlify/tree/main/skills/hellopay-payments).

<Note>
  The skill helps an agent **write** your integration. It is not an SDK you import at runtime, although it includes a copy-paste TypeScript client (`assets/hellopay-client.ts`).
</Note>

<Steps>
  <Step title="Install the skill" icon="download">
    The [`skills`](https://www.skills.sh) CLI detects the agents installed on your machine. No global install is needed:

    ```bash
    npx skills add hellopay-tech/hellopay-docs-mintlify --skill hellopay-payments
    ```
  </Step>
  <Step title="Ask your agent to build" icon="message">
    The skill activates automatically when your request mentions HelloPay, payins, payouts, PSE, Bre-B, Nequi, payment links, or webhooks.

    <Prompt description="Starter prompt for your coding agent" icon="robot">
      Using the HelloPay skill, add a PSE checkout to my backend: create the payin, poll until sourceData.pseUrl is ready, redirect the payer, and handle the payin.confirmed and payin.declined webhooks idempotently. Use the sandbox base URL and read the API key from HELLOPAY_API_KEY.
    </Prompt>
  </Step>
  <Step title="Test in the sandbox" icon="flask">
    Have the agent run the [sandbox test plan](/getting-started/sandbox#suggested-test-plan) before you go live.
  </Step>
</Steps>

### Install options

<CodeGroup>
```bash Project (default)
# Installs into the current project, for example ./.claude/skills/
npx skills add hellopay-tech/hellopay-docs-mintlify --skill hellopay-payments
```

```bash Global
# Installs for your user, for example ~/.claude/skills/, in every project
npx skills add hellopay-tech/hellopay-docs-mintlify --skill hellopay-payments -g
```

```bash Specific agents
# Installs only into the agents you choose
npx skills add hellopay-tech/hellopay-docs-mintlify --skill hellopay-payments -a claude-code -a cursor
```

```bash From the docs site
# Installs the same skill from docs.hellopay.com.co
npx skills add https://docs.hellopay.com.co
```

```bash Manual (Claude Code)
git clone https://github.com/hellopay-tech/hellopay-docs-mintlify
mkdir -p .claude/skills
cp -r hellopay-docs-mintlify/skills/hellopay-payments .claude/skills/
```
</CodeGroup>

<Tip>
  Add `-y` to skip prompts and `--copy` to copy files instead of symlinking them. Keep `SKILL.md`, `references/`, and `assets/` together in the `hellopay-payments/` folder.
</Tip>

### Keep it updated

```bash
npx skills update hellopay-payments   # update to the latest version
npx skills list                       # list installed skills
npx skills remove hellopay-payments   # uninstall
```

## Connect the docs MCP server

These docs run an [MCP](https://modelcontextprotocol.io) server at `https://docs.hellopay.com.co/mcp`. It lets an agent search the documentation while it works. It reads docs only: it cannot call the HelloPay API or see your account.

<CodeGroup>
```bash Claude Code
claude mcp add --transport http hellopay-docs https://docs.hellopay.com.co/mcp
```

```json Cursor (.cursor/mcp.json)
{
  "mcpServers": {
    "hellopay-docs": {
      "url": "https://docs.hellopay.com.co/mcp"
    }
  }
}
```

```json VS Code (.vscode/mcp.json)
{
  "servers": {
    "hellopay-docs": {
      "type": "http",
      "url": "https://docs.hellopay.com.co/mcp"
    }
  }
}
```
</CodeGroup>

You can also use the page menu (top right of every page) to connect the MCP server to Cursor or VS Code in one click.

## llms.txt and Markdown pages

| Resource | URL | Use it for |
| --- | --- | --- |
| Docs index | [`/llms.txt`](https://docs.hellopay.com.co/llms.txt) | A list of every page with a summary |
| Full docs | [`/llms-full.txt`](https://docs.hellopay.com.co/llms-full.txt) | All pages in one file |
| Any page as Markdown | Add `.md` to the URL, for example [`/getting-started/webhooks.md`](https://docs.hellopay.com.co/getting-started/webhooks.md) | Pasting one page into a chat |
| OpenAPI spec | [`/openapi.yaml`](https://docs.hellopay.com.co/openapi.yaml) | Generating clients and types |

<Warning>
  Whatever tool you use, keep the API key in an environment variable on your server, build against the [sandbox](/getting-started/sandbox) first, and review agent-written code that moves money before you deploy it.
</Warning>
