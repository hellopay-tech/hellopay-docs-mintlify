## Environments

HelloPay has two environments. Each one has its own portal, API base URL, and API keys.

| Environment | API base URL | Portal | Real money |
| --- | --- | --- | --- |
| Sandbox (staging) | `https://api.stg.hellopay.com.co` | [portal.stg.hellopay.com.co](https://portal.stg.hellopay.com.co) | No |
| Production | `https://api.hellopay.com.co` | [portal.hellopay.com.co](https://portal.hellopay.com.co) | Yes |

Sandbox keys only work with the sandbox API, and production keys only work with the production API. See [Sandbox](/getting-started/sandbox) for test data.

## Create an API key

<Steps>
  <Step title="Sign in to the portal">
    Open the portal for your environment: [sandbox](https://portal.stg.hellopay.com.co) or [production](https://portal.hellopay.com.co). If you do not have a user yet, see [Portal access](#portal-access).
  </Step>
  <Step title="Open Settings → API Keys">
    Go directly to [sandbox API keys](https://portal.stg.hellopay.com.co/settings/api-keys) or [production API keys](https://portal.hellopay.com.co/settings/api-keys).
  </Step>
  <Step title="Create and store the key">
    Click **Create API Key** and copy it right away. The key is only shown once. Store it in a secret manager or an environment variable such as `HELLOPAY_API_KEY`.
  </Step>
</Steps>

## Send the key

Send the key in the `X-API-Key` header on every request. Header names are case-insensitive, so `x-api-key` also works.

<CodeGroup>
```bash cURL
curl --request GET 'https://api.stg.hellopay.com.co/payins' \
  --header 'X-API-Key: YOUR_API_KEY'
```

```typescript TypeScript
const res = await fetch("https://api.stg.hellopay.com.co/payins", {
  headers: { "X-API-Key": process.env.HELLOPAY_API_KEY! },
});
```
</CodeGroup>

<Warning>
  Call HelloPay from your backend only. Never put the API key in a browser, mobile app, or public repository.
</Warning>

## Authentication errors

| Status | Cause | Fix |
| --- | --- | --- |
| `401 Unauthorized` | The `X-API-Key` header is missing (`"Unauthorized"`), or the key is invalid or revoked (`"Invalid API key"`) | Check the header name and that the key belongs to this environment |
| `403 Forbidden` | Your organization has an IP allowlist and the request came from another IP | Call from an allowlisted IP or ask support to update the list |

See [Errors](/getting-started/errors) for every error format.

## Portal access

Portal users are created by HelloPay. Ask [support](mailto:support@hellopay.com.co) or your commercial contact to create users for your team.
