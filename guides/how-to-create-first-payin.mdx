A **payin** is a request to collect money from a payer. Create it with `POST /payins`, show the payer what they need to pay, and wait for the final status.

<Info>
  Prefer a checkout page HelloPay hosts for you? Use [Payment links](/guides/payment-links) instead.
</Info>

## Choose a payment method

<Columns cols={3}>
  <Card title="PSE" icon="building-columns" href="/guides/payin-pse" arrow>
    The payer is redirected to their bank and pays from a savings or checking account.
  </Card>
  <Card title="Bre-B" icon="bolt" href="/guides/payin-breb" arrow>
    Instant payment. You show a one-time key or a QR code.
  </Card>
  <Card title="Nequi" icon="mobile-screen" href="/guides/payin-nequi" arrow>
    The payer approves a request in the Nequi app. No redirect or QR.
  </Card>
</Columns>

| | PSE | Bre-B | Nequi |
| --- | --- | --- | --- |
| `rail` | `PSE` | `BRE_B` | `NEQUI` |
| Extra object | `pse: { bank, personType }` | `breb: { keyType }` | None |
| What you show the payer | Redirect to `sourceData.pseUrl` | `sourceData.keyString` or `sourceData.qrString` | A message to approve in Nequi |
| Wait for rail data | Yes | Yes | No |
| Expiry check after | 30 min | 20 min | 15 min |

## General flow

<Visibility for="humans">
  <SequenceFlow
    title="Payin flow"
    steps={[
      { actor: "Your server", title: "Create the payin", detail: "POST /payins", icon: "server" },
      { actor: "HelloPay", title: "Returns the payin in PENDING", detail: "sourceData may be null", icon: "hourglass-half" },
      { actor: "Your server", title: "Poll until the rail data is ready", detail: "GET /payins/{id}", icon: "arrows-rotate" },
      { actor: "Payer", title: "Pays with PSE, Bre-B, or Nequi", icon: "user" },
      { actor: "HelloPay", title: "Sends the final webhook", detail: "payin.confirmed", icon: "bell" },
      { actor: "Your server", title: "Fulfills the order", icon: "box" },
    ]}
  />
</Visibility>

1. Send `POST /payins` with the amount, `inlineCustomer`, `rail`, and the method-specific object.
2. HelloPay returns the payin with `status: "PENDING"`.
3. For PSE and Bre-B, poll `GET /payins/{id}` until the data you need in `sourceData` is no longer `null`. The payin moves to `PROCESSING` and HelloPay sends `payin.processing`.
4. The payer completes the payment.
5. HelloPay sets the final status and sends `payin.confirmed`, `payin.declined`, or `payin.canceled`.
6. For hosted flows, the payer's browser returns to your `callbackUrl`.

## Request fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `amountInCents` | integer | Yes | Amount in cents. `100000` = 1,000 COP |
| `currency` | string | Yes | `COP` |
| `rail` | string | Yes | `PSE`, `BRE_B`, or `NEQUI` |
| `reference` | string | Yes | Your order ID. Echoed in responses and webhooks |
| `inlineCustomer` | object | Yes | Payer identity. See [the inlineCustomer object](/getting-started/core-concepts#the-inlinecustomer-object) |
| `pse` | object | When `rail` is `PSE` | `{ bank, personType }`. See [PSE](/guides/payin-pse) |
| `breb` | object | When `rail` is `BRE_B` | `{ keyType }`. See [Bre-B](/guides/payin-breb) |
| `callbackUrl` | string | No | Where the payer's browser returns after a hosted flow |

### Supported document types

Use one of these values in `inlineCustomer.idType`:

| Value | Description |
| --- | --- |
| `CO_CC` | Colombian citizenship ID (cédula de ciudadanía) |
| `CO_CE` | Colombian foreigner ID (cédula de extranjería) |
| `CO_NIT` | Colombian tax ID for businesses |
| `PASSPORT` | Passport |
| `MXN_RFC` | Mexican tax ID |

## Rail data (`sourceData`)

| Rail | `sourceData` fields | Filled |
| --- | --- | --- |
| `PSE` | `pseUrl`, `bank` | `pseUrl` is `null` at creation and filled asynchronously |
| `BRE_B` | `keyType`, `keyString`, `qrString`, `checkoutUrl` | `checkoutUrl` at creation. `keyString` and `qrString` asynchronously |
| `NEQUI` | `phone` | At creation |

## Poll for rail data

```typescript
async function waitFor<T>(payinId: string, pick: (p: any) => T | null, timeoutMs = 60_000) {
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    const res = await fetch(`https://api.stg.hellopay.com.co/payins/${payinId}`, {
      headers: { "X-API-Key": process.env.HELLOPAY_API_KEY! },
    });
    const payin = await res.json();
    if (["DECLINED", "CANCELED"].includes(payin.status)) throw new Error(payin.errorCode ?? payin.status);
    const value = pick(payin);
    if (value) return value;
    await new Promise((r) => setTimeout(r, 1500));
  }
  throw new Error("Timed out waiting for payin data");
}

// PSE: const pseUrl = await waitFor(payin.id, (p) => p.sourceData?.pseUrl);
```
