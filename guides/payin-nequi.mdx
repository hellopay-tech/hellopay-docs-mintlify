Use `rail: "NEQUI"` to send a payment request to the payer's Nequi account. HelloPay uses the mobile number in `inlineCustomer.phone`, and the payer approves the request in the Nequi app.

Before you start, read the [Payins overview](/guides/how-to-create-first-payin) and [configure webhooks](/getting-started/webhooks).

## How the Nequi flow works

<Visibility for="humans">
  <SequenceFlow
    title="Nequi payin"
    steps={[

      { actor: "HelloPay", title: "Returns PENDING, then sends the request to Nequi", detail: "payin.processing", icon: "paper-plane" },
      { actor: "Payer", title: "Approves the notification in the Nequi app", icon: "mobile-screen" },
      { actor: "HelloPay", title: "Sends the final webhook", detail: "payin.confirmed", icon: "bell" },
    ]}
  />
</Visibility>

1. Create the payin with `rail: "NEQUI"` and the payer's Nequi number in `inlineCustomer.phone`.
2. HelloPay returns the payin with `status: "PENDING"` and `sourceData.phone`.
3. HelloPay sends the request to Nequi. The payin moves to `PROCESSING` and HelloPay sends `payin.processing`.
4. Tell the payer to open Nequi and approve the request. There is nothing to redirect to or display.
5. Wait for `payin.confirmed` or `payin.declined`, or poll `GET /payins/{id}` until `status` is final.

<Warning>
  If the payer does not approve within **15 minutes**, the payin becomes `DECLINED` with `errorCode: NEQUI_PAYIN_EXPIRED`. If Nequi rejects the request, it becomes `DECLINED` with `errorCode: VENDOR_REJECTED`.
</Warning>

## Request

```bash
curl --request POST 'https://api.stg.hellopay.com.co/payins' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "amountInCents": 100000,
    "currency": "COP",
    "rail": "NEQUI",
    "reference": "INV-2026-001",
    "inlineCustomer": {
      "name": "John Doe",
      "idType": "CO_CC",
      "idNumber": "1000000001",
      "email": "john.doe@example.com",
      "phone": "+573001234567"
    }
  }'
```

| Field | Required | Description |
| --- | --- | --- |
| `inlineCustomer.phone` | Yes | The payer's Nequi number, in `+573XXXXXXXXX` format. The payment request goes to this number |
| `callbackUrl` | No | Not used by Nequi, because the payer never leaves your app |

<Note>
  Do not send a `nequi` object. Nequi payins need no method-specific object, and the API rejects unknown fields with `400`.
</Note>

## Response

```json
{
  "id": "123e4567-e89b-12d3-a456-426614174000",
  "amount": 1000,
  "amountInCents": 100000,
  "currency": "COP",
  "status": "PENDING",
  "rail": "NEQUI",
  "reference": "INV-2026-001",
  "inlineCustomer": {
    "name": "John Doe",
    "idType": "CO_CC",
    "idNumber": "1000000001",
    "email": "john.doe@example.com",
    "phone": "+573001234567"
  },
  "errorCode": null,
  "sourceData": {
    "phone": "+573001234567"
  }
}
```

The response is shortened here. See the [Payins overview](/guides/how-to-create-first-payin#sample-response) for every field.

`sourceData.phone` is the number the request was sent to. It is not a payment confirmation: wait for the final status.
