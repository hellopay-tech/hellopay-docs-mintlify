Use `rail: "PSE"` to let the payer authorize the payment from their Colombian bank account. The payer is redirected to their bank and then back to your `callbackUrl`.

Before you start, read the [Payins overview](/guides/how-to-create-first-payin) and [configure webhooks](/getting-started/webhooks).

## How the PSE flow works

    title="PSE payin"
    steps={[

      { actor: "HelloPay", title: "Returns PENDING with pseUrl: null", icon: "hourglass-half" },
      { actor: "Your server", title: "Polls until pseUrl is set", detail: "GET /payins/{id}", icon: "arrows-rotate" },
      { actor: "Payer", title: "Is redirected to pseUrl and authorizes at the bank", icon: "building-columns" },
      { actor: "HelloPay", title: "Sends the final webhook", detail: "payin.confirmed", icon: "bell" },
      { actor: "Payer", title: "Returns to your callbackUrl", icon: "arrow-right-to-bracket" },
    ]}
  />
</Visibility>

1. Create the payin with `rail: "PSE"` and the payer's bank in `pse.bank`.
2. HelloPay returns the payin with `status: "PENDING"` and `sourceData.pseUrl: null`.
3. Poll `GET /payins/{id}` every 1–2 seconds until `sourceData.pseUrl` is set (usually a few seconds).
4. Redirect the payer to `sourceData.pseUrl`. They authorize the payment at their bank.
5. HelloPay sends `payin.confirmed`, `payin.declined`, or `payin.canceled`.
6. The payer's browser returns to your `callbackUrl`. Show a status page, but use the webhook to fulfill the order.

<Warning>
  After 30 minutes, HelloPay checks the payin with PSE. If the payer never started the payment, it becomes `DECLINED` with `errorCode: PSE_PAYIN_EXPIRED`. If the payment is still in progress at the bank, it keeps its status until the bank answers, so always wait for the final webhook.
</Warning>

## Request

<CodeGroup>
```bash cURL
curl --request POST 'https://api.stg.hellopay.com.co/payins' \
  --header 'X-API-Key: YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "amountInCents": 100000,
    "currency": "COP",
    "rail": "PSE",
    "reference": "INV-2026-001",
    "inlineCustomer": {
      "name": "John Doe",
      "idType": "CO_CC",
      "idNumber": "1000000001",
      "email": "john.doe@example.com",
      "phone": "+573001234567"
    },
    "pse": {
      "bank": "CO_BANCOLOMBIA",
      "personType": "INDIVIDUAL"
    },
    "callbackUrl": "https://your-app.com/checkout/return"
  }'
```

```typescript TypeScript
const res = await fetch("https://api.stg.hellopay.com.co/payins", {
  method: "POST",
  headers: { "X-API-Key": process.env.HELLOPAY_API_KEY!, "Content-Type": "application/json" },
  body: JSON.stringify({
    amountInCents: 100000,
    currency: "COP",
    rail: "PSE",
    reference: "INV-2026-001",
    inlineCustomer: {
      name: "John Doe",
      idType: "CO_CC",
      idNumber: "1000000001",
      email: "john.doe@example.com",
      phone: "+573001234567",
    },
    pse: { bank: "CO_BANCOLOMBIA", personType: "INDIVIDUAL" },
    callbackUrl: "https://your-app.com/checkout/return",
  }),
});
const payin = await res.json();
```
</CodeGroup>

### PSE fields

| Field | Required | Description |
| --- | --- | --- |
| `pse.bank` | Yes | The payer's bank. Use a code from [Supported banks](#supported-banks) |
| `pse.personType` | Yes | `INDIVIDUAL` for a personal account, `BUSINESS` for a company account |
| `callbackUrl` | Recommended | Where the payer returns after leaving PSE |

The shared fields (`amountInCents`, `currency`, `reference`, `inlineCustomer`) are described in the [Payins overview](/guides/how-to-create-first-payin#request-fields).

Responses are shortened here. See the [Payins overview](/guides/how-to-create-first-payin#sample-response) for every field.

- `sourceData.pseUrl` is the only value you need to redirect the payer. It is `null` until HelloPay finishes preparing the PSE flow.
- `sourceData.bank` echoes `pse.bank`. `personType` is not returned.
